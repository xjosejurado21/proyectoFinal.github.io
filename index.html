      Cómo está construido este universo

      Arquitectura narrativa

      El viaje está pensado como un mapa interactivo construido con HTML semántico y animaciones CSS. Cada planeta y cada país provienen de un único objeto JavaScript, lo que facilita ampliar el portafolio sin tocar el marcado principal.

      Interacciones accesibles

      El coche se desplaza suavemente mediante variables CSS actualizadas desde JavaScript. Se emplean transiciones de tipo spring y prefers-reduced-motion para respetar la accesibilidad. Además, los países son botones navegables por teclado.

      Pila tecnológica

      Trabajo habitualmente con HTML, CSS, JavaScript y PHP, apoyándome en bases de datos MySQL y frameworks modernos según las necesidades. También diseño APIs limpias y me apoyo en Git para versionado colaborativo.

      Iteración continua

      Cada mundo representa una etapa de aprendizaje. Al documentar cómo está hecho el código, refuerzo mi proceso de mejora continua y ofrezco a cada cliente transparencia sobre el camino técnico seguido.
